# Notebooks

Le but du notebook est de pouvoir documenter son code et d'avoir des  scripts intéractifs, entre les cellules de codes et les cellules de markdown. C'est fait pour être utilisé par un humain, produire des plots, des prints... pas simplement 'run'.

Super pour explorer, tester, faire des tutoriel ou des exercices.

Jupyter notebook a tout ce qu'il faut et il peut être utilisé avec Python ou R.
