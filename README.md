# Python guide for R users

Welcome to the README of this guide.

Guide link: https://calhenry.github.io/Python-guide-for-R-users/

> Currently only in french

The guide is meant for R users moving on to Python, but it is also relevant for beginner/ medium level in programmation.  
The book is **opinionated** and based on my personal expriences and struggles. The main goal is to share the setup i recommand regarding Python for Data sciences along with explanations on the *what*, the *why* and the *how*.
